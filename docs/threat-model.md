# Modelo de amenazas (STRIDE)

**Alcance:** Atención al cliente omnicanal con IA, sin despliegue en la nube (no hay AWS en este
proyecto).

Para cada amenaza se indica:

- la mitigación **implementada**, con el archivo donde vive;
- la **evidencia**: el test o la **mutación** (`npm run test:mutations`, que rompe la regla a
  propósito y exige que un test falle) que la cubre;
- el **riesgo residual**.

Lo que no está implementado se dice. Las rutas son relativas al repo del backend salvo que se
indique el repo.

## 1. Componentes y fronteras de confianza

```
 Navegador del CLIENTE (widget)                 Navegador del AGENTE (panel)
   │ REST /api/widget/*  (cookie httpOnly         │ REST /api/*  (Bearer, access token en memoria)
   │   atencion_ia_widget + X-Requested-With)     │ cookie httpOnly de refresh (solo /api/auth)
   │ WS /ws       eventos (solo recepción)        │ WS /ws        eventos (solo recepción)
   │ WS /ws/voice audio PCM + señalización        │ WS /ws/voice  audio PCM + señalización
   │                                              │
   │◄═════════════ WebRTC (audio cifrado DTLS-SRTP, de navegador a navegador) ═════════════►│
   │                 [STUN/TURN de terceros si se configuran: ICE_SERVERS]                   │
   ▼                                              ▼
 ─────────────────────────── frontera 1: Internet (TLS en un despliegue real) ──────────────
 API Express + servidores WS (una o varias instancias)
   │ Prisma / SQL parametrizado     │ Redis: rate limit, BullMQ,          │ HTTPS / WSS
   ▼                                │ pub/sub eventos y voz               ▼
 PostgreSQL + pgvector              ▼                              Proveedores externos:
 (esquema y reglas en          Worker: avisos de escalamiento,     Anthropic (chat, intención)
  atencion-ia-database)        índice RAG, barrido y purga         Voyage (embeddings)
                                                                   Deepgram (STT/TTS de voz)
```

| Frontera                                | Qué cruza                                                     | Qué NO es confiable                                                                         |
| --------------------------------------- | ------------------------------------------------------------- | ------------------------------------------------------------------------------------------- |
| Navegador del cliente → API             | mensajes, audio, sesión anónima, consentimiento               | **todo**: el cliente es anónimo                                                             |
| Navegador del agente → API              | credenciales, tokens, respuestas, acciones sobre casos        | todo lo que llega del navegador (una cuenta robada se comporta igual)                       |
| Navegador ↔ navegador (WebRTC)          | audio en vivo entre cliente y agente                          | la otra punta; la red (y un TURN, si hay)                                                   |
| API → navegador (señalización relevada) | ofertas/respuestas SDP y candidatos ICE del otro participante | el contenido de la señal (lo escribió el otro navegador)                                    |
| API/worker → proveedores de IA y voz    | texto del cliente, fragmentos de la KB, audio                 | la **respuesta** del modelo (manipulable con prompt injection); lo que el proveedor retiene |
| Base de conocimiento → prompt           | artículos publicados por un admin                             | (confiable en origen, pero se trata como dato, no como instrucción)                         |
| API/worker → PostgreSQL / Redis         | consultas, trabajos, eventos                                  | confiables en la red interna (ver residuales)                                               |

## 3. Amenazas propias de este dominio (resumen)

1. **Suplantación de un agente.** Sesión en memoria + refresh rotativo con detección de reutilización
   - bloqueo progresivo. En voz se exige además participación registrada y el caso asignado.
     Desde la Fase 7, **MFA TOTP** (obligatoria para admin) con anti-replay y códigos de respaldo de
     un solo uso (§2.7).
2. **Fuga de datos de un cliente hacia otro vía RAG.** Cuatro capas, una de ellas en la **base**
   (trigger 013). Además hay un test con un "secreto" sembrado y mutaciones de cada capa.
3. **Abuso del canal de voz para agotar créditos de IA.** Siete límites por conexión, sesión y
   cliente. **Falta un tope global** de gasto.
4. **Señalización WebRTC.** El servidor decide el destinatario (el cliente no puede dirigirla) y la
   valida con zod. Funciona entre instancias por Redis. El audio entre personas va cifrado
   extremo a extremo por el navegador (DTLS-SRTP).
5. **Audio en tránsito y en reposo.** No se guarda. En tránsito necesita TLS en el despliegue.
   La transcripción tiene retención forzada por la base.
6. **Adjuntos como vía de ataque a la IA.** El modelo nunca ve el archivo ni su nombre, solo una
   señal del servidor; cinco mutaciones lo vigilan (77–81).

## 4. Riesgos aceptados o pendientes (fuera del alcance de este proyecto)

| Pendiente                                 | Por qué importa                                                             | Qué haría falta                                                                                                                                              |
| ----------------------------------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| **TLS** (HTTPS/WSS)                       | Sin él, credenciales, mensajes y audio viajan en claro fuera de `localhost` | Proxy inverso con TLS en el despliegue (no hay despliegue en este proyecto)                                                                                  |
| **Tope global de gasto** de IA y voz      | Muchas sesiones anónimas multiplican los topes por cliente                  | Contador diario global en Redis + alerta + corte                                                                                                             |
| **MFA obligatoria** para los asesores     | Un asesor sin MFA depende solo de su contraseña                             | Exigirla a todos (hoy: obligatoria para admin, opcional para asesores)                                                                                       |
| **Borrado a pedido** del cliente          | Derecho de supresión de la ley de datos personales                          | Flujo verificado de supresión ([docs/privacy-voice.md](privacy-voice.md) §5). El del staff ya existe (anonimización, [data-retention.md](data-retention.md)) |
| **Antivirus** de los adjuntos             | Un PDF o una imagen pueden traer malware que el filtro de formato no ve     | Escaneo (p. ej. ClamAV) antes de servir el archivo                                                                                                           |
| **Ocultar la IP** en WebRTC               | El otro participante ve la IP pública                                       | TURN propio y `iceTransportPolicy: "relay"`                                                                                                                  |
| Verificación de **identidad** del cliente | El cliente es anónimo; la voz se puede clonar                               | Autenticación bancaria del cliente (fuera del alcance)                                                                                                       |
| Proveedores **reales** sin verificar      | Retención de datos y comportamiento real de Anthropic, Voyage y Deepgram    | Probar con credenciales (cierre del proyecto)                                                                                                                |
| Límite de **conexiones WebSocket por IP** | Agotar sockets o memoria                                                    | En el proxy del despliegue                                                                                                                                   |
